# AI Project

## Session 1 - Poem Chatbot

This repository contains my Session 1 homework: a chatbot that understands a user's message and responds with an appropriate line of classical Chinese poetry.

### Project Structure

- `session-01/design.md` — original Mermaid architecture design
- `session-01/poem_bot.py` — poem chatbot implementation
- `session-01/generated_architecture.md` — Mermaid architecture generated from the final implementation
- `course-demos/common/llm.py` — shared LLM helper reused by the chatbot

### Run

```bash
python3 session-01/poem_bot.py
